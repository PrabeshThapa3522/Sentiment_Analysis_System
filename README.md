# Sentiment Analysis System

## Objective

Build a sentiment analysis system that classifies text into:

- Positive
- Negative
- Neutral

---

## Features

- Text preprocessing
- Tokenization
- Stopword removal
- Lemmatization
- Word2Vec embeddings
- Logistic Regression baseline
- LSTM Deep Learning model
- RNN Deep Learning model
- Accuracy, Precision, Recall and F1-score
- Model comparison
- Streamlit web application

---

## Technologies

- Python
- TensorFlow
- Scikit-learn
- Gensim
- Pandas
- NumPy
- NLTK
- Streamlit

---
